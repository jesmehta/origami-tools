Verticals · evenly spread

Number: first and last vertical on the rectangle edges. Distance / minor diagonal (= 2 × distance): verticals from x = 0 at that spacing; a last vertical beyond the right edge is kept (grey) so the grid fills the rectangle.

Verticals · free
V mm

Always exactly vertical. Start from an even spread, then drag / type / add / delete verticals in Verticals mode. The lines bend (refract) at each vertical so every rhombus vertex lands on one.

Rhombus

θ is the angle of a rhombus side to the horizontal (h = distance × tan θ, taken from the first section V1–V2). Number of chains: the vertical diagonals stack to fill the rectangle height exactly (2h = H ÷ chains), and θ follows. Every rhombus has the same vertical diagonal 2h.

Grid position

y offset shifts the whole grid vertically (0 = the first chain's top vertex sits on the top edge; drag in Grid mode). "Chains cross on" picks which verticals carry the crossing points of the chains; the other verticals carry the offset "1.5" rows.
