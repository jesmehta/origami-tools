Rhombus

You set one angle; the rest is computed. Both options give identical rhombi when the verticals are evenly spaced. When they are not, same height keeps every vertical diagonal the same length (the angles adapt), and exact θ keeps θ on the left half of each rhombus (the diagonal length adapts). The height is taken from the first section, V1–V2.

Chains

A chain is one up/down pair of lines that crosses on every second vertical. Same: all chains cross on V1, V3, V5… — parallel bands. Alternating: odd chains cross on V2, V4… instead, so the chains interlock into an X lattice. Changing this re-applies it to every chain (top to bottom).
